## ✨ Concept

The Tactile Textile System translates the richness of physical fabric — beadwork, quilting, woven structure, embroidery — into a digital UI language. It's the third material pillar in the design system family, completing the trilogy:

```
💎 Jewelmorphism   ← crystal, light, depth
🪵 Woodmorphism    ← grain, warmth, organic
🧵 Textile         ← pattern, texture, hand-made
```

---

## 🎭 Aesthetic Modes

| Mode | Inspiration | Visual Character |
|---|---|---|
| **Beadwork** | West African & Native beading traditions | Dense pattern, jewel-dot grid, rhythmic color |
| **Quilted** | American quilt-making | Geometric block structure, warm contrast, stitched seams |
| **Woven** | Jacquard textile, tapestry | Interlocking line structure, pixel-like texture |
| **Embroidery** | Hand-stitched illustrative fabric | Soft outlines, thread-like strokes, floral motifs |

---

## 🎨 Design Tokens

| Token | Value | Description |
|---|---|---|
| `--textile-stitch` | `2px dashed` | Seam / edge treatment |
| `--textile-bead` | `radial-gradient(circle, ...)` | Bead dot fill |
| `--textile-grid` | `8px` | Base weave unit |
| `--textile-warm` | `#D4845A` | Rust clay |
| `--textile-deep` | `#3B1F3A` | Deep plum |
| `--textile-gold` | `#E8C96B` | Embroidery gold |
| `--textile-cream` | `#F5EDE0` | Natural ground |
